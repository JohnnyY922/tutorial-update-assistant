# Trace · 教程变更定位助手

根据《教程变更定位助手 PRD V0.1》、`tokens.css` 和 `design-system.html` 制作的完整交互原型（分步版 v0.2）。采用 HTML、Tailwind CSS 3.4.17 与原生 JavaScript，默认深色主题，支持桌面与移动端布局。

## 本地预览

在本目录运行：

```bash
python3 preview.py
```

打开 http://127.0.0.1:5173 。源文件保存后，浏览器自动刷新。也可以双击 `启动预览.command`。端口被占用时可运行 `python3 preview.py --port 5174`。

这是浏览器 ES 模块应用，需要通过 HTTP 访问，不能直接双击 index.html 使用。Python 3 只负责提供本地静态文件，不参与读取用户文档；没有上传接口。Tailwind 编译产物和 JSZip 已打包在本地，日常预览无需 npm 或 CDN。

## 页面层级与主流程

初次打开只展示上传首页，不预载分析结果。

1. **导入教程**：选择 Word 文档，或点击“用示例体验一次”。上传后显示文档摘要，下一步再确认目录。
2. **描述变更**：独立页面填写本次变更和新旧内容；“检查范围与例外”移入二级设置窗口。
3. **核对结果**：独立页面展示筛选与结果清单；点击某条内容才打开详情抽屉。

目录调整、检查范围、任务记录、使用指南和原文上下文均按需打开二级窗口。详情抽屉支持上一条、下一条，并保留列表筛选状态。支持步骤返回和浏览器前进/后退。

正文与输入区调整到 15–16px，结果标题 16px，详情正文 16px，辅助信息 12–14px。页面使用单列主流程和更宽的留白，移动端详情改为全屏。

## 已实现的交互
- Word 上传：点击或拖拽单个 .docx；格式、大小、损坏文件、空正文与超限提示。
- 文档解析：标题、普通段落、列表与普通表格，保留段落顺序和表格行列编号。
- 目录确认：预览全文、编辑识别标题、从段落拆分新教程、合并至上一篇。
- 本地分析：逐篇处理，真实完成数；区分建议修改、待确认、无需修改。
- 结果核对：按教程/状态/关键词组合筛选；原文与改写突出显示；查看上下文。
- 复制和导出：复制原文、建议或确认事项；全部/当前筛选导出带 BOM 的 CSV。
- 任务状态：配置变更后标记旧结果，旧结果保留文档和配置快照；当前会话历史记录。
- 原型演示：内置 6 篇教程，18 条候选结果（12 建议修改、2 待确认、4 无需修改）；帮助中可体验失败重试、空白任务、下载示例 Word。
- 键盘支持：`/` 搜索，`⌘/Ctrl + Enter` 分析，`Esc` 关闭弹窗。

## 原型边界

本版本未接入 AI 或内部后台。分析采用规则匹配，支持名称/明确描述替换、英文词边界、通用 AI Agent 概念、链接和代码保护，以及缺少新路径的待确认状态；不能替代真正的上下文语义分析，自定义自然语言范围和复杂例外仍需人工核对。完整产品后续应将 `engine.mjs` 的分析入口替换为经过验证的服务。

图片、截图、文本框、批注不分析；不声称覆盖这些内容。最多处理 20 MB 文件、10,000 个文字段落、200 万字，超过限制会直接提示拆分，不会静默截断。复杂嵌套表格和非标准 Word 结构仍需要用真实资料做兼容性验证。

任务和文档仅在当前页面内存保存，刷新后回到上传首页。修改目录只影响解析视图，不改写原 Word。无账号、云存储、后台接入或自动发布。

## 文件结构

- `index.html`：页面骨架与 SVG 图标。
- `app.js`：页面状态、交互、文档预览、导出与任务记录。
- `engine.mjs`：可独立运行的分析规则、分组与 CSV 生成。
- `parser.js`：DOCX XML 解析。
- `tokens.css`：原文件夹提供的设计令牌副本。
- `styles.css`：组件样式与响应式断点。
- `tailwind.css`：本地编译的 Tailwind 样式。
- `input.css` / `tailwind.config.cjs`：Tailwind 源与配置。
- `vendor/jszip.min.js`：本地 Word ZIP 解压依赖。
- `preview.py`：仅监听 127.0.0.1 的预览服务，提供自动刷新。

## 修改 Tailwind 工具类后重新构建

普通样式改动只需编辑 `styles.css`。新增 Tailwind 类名后运行：

```bash
npm install
npm run build:css
```

打包的前端无运行时安装要求。第三方库许可证保存在 `vendor/` 中。
